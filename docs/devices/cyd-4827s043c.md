# CYD 4827S043C

A CYD ("Cheap Yellow Display") board with a 4.3" 480x272 RGB display.

## Feature support

| Feature | Status | Notes |
|-|-|-|
| SD card | ✅ | |
| External I2C | ✅ | GPIO-17 (SDA), GPIO-18 (SCL) |
| Bluetooth | ✅ | BLE |
| Touch | ✅ | `GT911` |
| Backlight control | ✅ | Brightness control |
